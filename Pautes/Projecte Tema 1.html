Projecte Tema 1 — CineApp

1. Objectiu

Desenvolupa una aplicació web en PHP per gestionar un petit catàleg de pel·lícules.

2. Funcionament general de l'aplicació

CineApp serà una aplicació per consultar i gestionar un catàleg de pel·lícules.

L'usuari haurà de poder:

  1. iniciar sessió;
  2. mantenir la sessió mentre navega per l'aplicació;
  3. recordar opcionalment el nom d'usuari mitjançant una cookie;
  4. consultar el catàleg de pel·lícules;
  5. consultar la fitxa d'una pel·lícula;
  6. cercar pel·lícules;
  7. crear pel·lícules;
  8. modificar pel·lícules;
  9. eliminar pel·lícules;
  10. marcar pel·lícules com a preferides;
  11. treure pel·lícules dels preferits;
  12. consultar les seves pel·lícules preferides.

Les funcionalitats de gestió i consulta estaran protegides mitjançant una sessió.

3. Base de dades

En el Moodle hi ha el fitxer:

cineapp.sql

Aquest script crearà la BD i les dades inicials necessàries.

No cal dissenyar ni crear la base de dades des de zero.

La base de dades estarà formada per dues taules.

3.1. genere

Camp Tipus Restriccions
id INT PK, AUTO_INCREMENT
nom VARCHAR(50) NOT NULL, UNIQUE

La base de dades inclourà diversos gèneres inicials.

3.2. pelicula

Camp Tipus Restriccions
id INT PK, AUTO_INCREMENT
titol VARCHAR(100) NOT NULL, UNIQUE
data_estrena DATE NOT NULL
durada INT NOT NULL
sinopsi TEXT NOT NULL
genere_id INT NOT NULL, FK

5. Configuració i connexió a la base de dades

5.1. config/config.inc.php

Crea el fitxer:

config/config.inc.php

Aquest fitxer contindrà la configuració necessària per connectar-se a la base de dades.

5.2. model/persistence/class_db.php

Crea una classe db que s'encarregui de la connexió amb MySQL.

La classe haurà de proporcionar els mètodes necessaris perquè els DAO puguin:

  • executar consultes;
  • obtenir resultats;
  • tancar la connexió quan sigui necessari.

Els DAO hauran d'heretar d'aquesta classe.

6. Pàgina d'inici i autenticació

6.1. index.php

index.php serà el punt d'entrada de l'aplicació.

Haurà de comprovar si l'usuari ha iniciat sessió.

  • Si no està autenticat, s'haurà de mostrar el formulari de login.
  • Si ja està autenticat, haurà d'accedir directament a la pàgina principal.

6.2. view/form_login.php

Crea un formulari amb:

  • nom d'usuari;
  • contrasenya;
  • checkbox Recordar usuari;
  • botó Entrar.

El formulari utilitzarà:

method="post"

i enviarà les dades al controlador de login.

6.3. controller/login_ctl.php

El controlador de login haurà de:

  1. recuperar les dades del formulari mitjançant $_POST;
  2. comprovar que les dades necessàries existeixen;
  3. validar les credencials;
  4. crear la sessió si el login és correcte;
  5. gestionar la cookie «Recordar usuari»;
  6. redireccionar a la pàgina principal.

Les credencials vàlides estaran definides en un array associatiu de PHP proporcionat dins del projecte.

No cal implementar un sistema de registre d'usuaris ni una base de dades d'usuaris.

Si les credencials no són correctes, s'haurà de mostrar un missatge d'error i permetre tornar a intentar el login.

7. Sessions

L'aplicació utilitzarà:

$_SESSION['userName']

per indicar que l'usuari està autenticat.

Recorda iniciar la sessió amb:

session_start();

abans de treballar amb $_SESSION.

Les pàgines protegides hauran de comprovar que existeix:

$_SESSION['userName']

Si no existeix, l'usuari haurà de ser redirigit al login.

7.1. view/header.php

Crea un header.php que sigui reutilitzat per les diferents vistes.

Quan l'usuari estigui autenticat, haurà de mostrar:

Usuari: nomUsuari

i un enllaç:

Tancar sessió

El footer.php tancarà l'estructura HTML comuna de les pàgines.

7.2. controller/logout_ctl.php

Crea el controlador de logout.

Quan l'usuari tanqui la sessió:

  1. elimina la informació de sessió necessària;
  2. redirecciona l'usuari al login.

8. Cookie «Recordar usuari»

Quan l'usuari marqui:

Recordar usuari

el nom d'usuari s'haurà de guardar en una cookie.

Quan torni al formulari de login:

  • el camp d'usuari haurà d'aparèixer emplenat;
  • el checkbox haurà d'aparèixer marcat.

Si no marca el checkbox, la cookie s'haurà d'eliminar si existia.

Pots crear funcions específiques per crear i esborrar cookies, com hem fet durant el tema.

9. Pàgina principal

view/home.php

Una vegada autenticat, l'usuari accedirà a la pàgina principal.

Haurà de mostrar, com a mínim:

Veure pel·lícules
Cercar pel·lícules
Afegir pel·lícula
Veure preferits
Tancar sessió

La pàgina haurà d'incloure:

header.php

i:

footer.php

model/business/class_pelicula.php

Com a mínim haurà de contenir:

id
titol

sinopsi

Utilitza mètodes per modificar i consultar les propietats de l'objecte.

11. DAO de pel·lícules

model/persistence/class_peliculaDAO.php

Crea el DAO de pel·lícules.

El DAO haurà d'heretar de:

db

i haurà de permetre, com a mínim:

  • obtenir totes les pel·lícules;
  • obtenir una pel·lícula per id;
  • inserir una pel·lícula;
  • modificar una pel·lícula;
  • eliminar una pel·lícula;
  • cercar pel·lícules.

Les consultes a la base de dades s'han de realitzar des del DAO, no des de les vistes.

12. Llistat de pel·lícules

controller/list_pelicules_ctl.php

Crea el controlador que recuperarà les pel·lícules mitjançant el DAO i les passarà a la vista.

view/list_pelicules.php

La vista mostrarà, com a mínim:

  • títol;
  • data d'estrena;
  • durada;
  • gènere.

El gènere s'haurà de mostrar pel seu nom, no mitjançant el valor numèric de genere_id.

Per obtenir aquesta informació hauràs d'utilitzar una consulta que relacioni:

pelicula
genere

mitjançant un:

JOIN

Per a cada pel·lícula hi haurà opcions per:

Veure
Modificar
Eliminar
Afegir/treure dels preferits

Les id de les pel·lícules es podran enviar als controladors mitjançant paràmetres GET.

13. Veure el detall d'una pel·lícula

controller/view_pelicula_ctl.php

Aquest controlador haurà de rebre la id de la pel·lícula mitjançant GET.

Per exemple:

view_pelicula_ctl.php?id=3

Haurà de consultar el DAO i recuperar la pel·lícula.

Si la pel·lícula existeix, carregarà:

view/view_pelicula.php

Si no existeix, mostrarà un missatge d'error.

view/view_pelicula.php

Mostra:

  • títol;
  • data d'estrena;
  • durada;
  • gènere;
  • sinopsi.

La data s'haurà de mostrar en format:

dia-mes-any

Pots utilitzar:

DateTime

14. Crear una pel·lícula

view/form_create_pelicula.php

Crea un formulari amb:

  • títol;
  • data d'estrena;
  • durada;
  • sinopsi;
  • gènere.

El camp de gènere haurà de ser un:

<select>

Les opcions del desplegable s'han d'obtenir de la base de dades.

Per a cada opció:

  • es mostrarà el nom del gènere;
  • el valor enviat serà la seva id.

La data d'estrena haurà d'aparèixer inicialment amb la data actual.

El camp durada haurà de ser:

<input type="number">

controller/create_pelicula_ctl.php

Aquest controlador haurà de:

  1. recuperar les dades mitjançant $_POST;
  2. comprovar que els camps obligatoris tenen valor;
  3. validar les dades;
  4. crear l'objecte pelicula;
  5. utilitzar el DAO per inserir-lo;
  6. mostrar un missatge de confirmació o d'error.

15. Validació amb expressions regulars

El títol de la pel·lícula s'haurà de validar també mitjançant una expressió regular amb:

preg_match()

El títol:

  • no podrà estar buit;
  • haurà de tenir entre 2 i 100 caràcters;
  • només podrà contenir lletres, números, espais i signes de puntuació habituals en títols, com :, - i '.

Recorda: preg_match() retorna un valor que permet saber si el text compleix o no el patró indicat.

Aquesta validació s'haurà de fer al controlador abans d'intentar inserir la pel·lícula.

16. Modificar una pel·lícula

controller/edit_pelicula_ctl.php

Aquest controlador haurà de gestionar tant l'obertura del formulari com l'enviament de les dades modificades.

Quan rebi una id mitjançant GET:

  1. recuperarà la pel·lícula;
  2. comprovarà que existeix;
  3. carregarà el formulari d'edició.

Quan rebi el formulari mitjançant POST:

  1. recuperarà les dades;
  2. validarà les dades;
  3. modificarà l'objecte pelicula;
  4. utilitzarà el DAO per actualitzar la base de dades.

view/form_edit_pelicula.php

El formulari haurà de mostrar les dades actuals de la pel·lícula.

El gènere actual haurà d'aparèixer seleccionat per defecte:

selected

La id de la pel·lícula s'haurà d'enviar al controlador.

La data haurà de poder ser modificada i el camp de durada haurà de continuar sent:

<input type="number">

17. Eliminar una pel·lícula

controller/delete_pelicula_ctl.php

Afegeix l'opció d'eliminar una pel·lícula.

La id de la pel·lícula s'enviarà mitjançant GET.

Abans d'eliminar-la, demana confirmació a l'usuari.

Si la pel·lícula existeix:

  • elimina-la mitjançant el DAO;
  • mostra un missatge de confirmació.

Si no existeix:

  • mostra un missatge d'error.

18. Cercar pel·lícules

Crea una funcionalitat de cerca.

view/cerca_pelicules.php

Mostra un formulari que permeti introduir un text de cerca.

El formulari utilitzarà:

GET

i enviarà el text al controlador:

controller/cerca_pelicules_ctl.php

controller/cerca_pelicules_ctl.php

El controlador haurà de:

  1. recuperar el text mitjançant $_GET;
  2. comprovar que s'ha introduït alguna dada;
  3. demanar al DAO les pel·lícules que coincideixen amb la cerca;
  4. passar els resultats a la vista;
  5. mostrar un missatge si no s'ha trobat cap pel·lícula.

La cerca es farà pel títol.

19. Sistema de preferits

Cada usuari podrà marcar pel·lícules com a preferides.

Els preferits es guardaran en una cookie.

La cookie contindrà un array amb les id de les pel·lícules preferides.

Com que una cookie no permet guardar directament un array, hauràs d'utilitzar:

serialize()

per guardar-lo i:

unserialize()

per recuperar-lo.

19.1. Afegir una pel·lícula als preferits

Quan l'usuari marqui una pel·lícula:

  1. recupera la cookie dels preferits, si existeix;
  2. converteix el seu contingut en un array amb unserialize();
  3. afegeix la id de la pel·lícula;
  4. converteix l'array amb serialize();
  5. guarda novament la cookie.

No s'ha de guardar dues vegades la mateixa id.

19.2. Treure una pel·lícula dels preferits

Quan l'usuari desmarqui una pel·lícula:

  1. recupera l'array de preferits;
  2. elimina la id corresponent;
  3. torna a guardar l'array a la cookie.

19.3. Veure els preferits

Crea:

controller/preferits_ctl.php

i:

view/list_preferits.php

La pàgina haurà de mostrar únicament les pel·lícules les id de les quals apareixen a la cookie.

Si no hi ha cap pel·lícula preferida, mostra:

No tens cap pel·lícula preferida.

20. Arrays i funcions

Al projecte hauràs d'utilitzar funcions pròpies per evitar repetir codi.

Per exemple, pots crear funcions per:

  • comprovar l'autenticació;
  • crear i esborrar cookies;
  • recuperar els preferits;
  • guardar els preferits;
  • validar dades.

També hauràs de treballar amb arrays, especialment:

  • l'array associatiu d'usuaris;
  • els arrays de resultats obtinguts del DAO;
  • l'array de preferits recuperat de la cookie.

21. Control d'accés

Les operacions següents només estaran disponibles per a usuaris autenticats:

  • veure el catàleg;
  • veure una pel·lícula;
  • cercar;
  • crear;
  • modificar;
  • eliminar;
  • gestionar preferits.

Si un usuari no autenticat intenta accedir directament a una d'aquestes pàgines mitjançant la URL, haurà de ser redirigit al login.

No n'hi ha prou amb ocultar els enllaços a la vista: el controlador també haurà de controlar l'accés.
